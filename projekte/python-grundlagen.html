Programmier-Grundlagen mit GPT-Mentor

Neben den Web-Projekten lerne ich die Basis der Programmierung von Grund auf, mit vielen kleinen Übungsprojekten in Python und einem KI-Mentor als Ausbilder.

Warum Grundlagen, wenn KI den Code schreiben kann

Weil ich verstehen will, was ich abgebe. KI-Tools beschleunigen die Arbeit enorm, aber nur, wenn ich beurteilen kann, ob eine Lösung gut ist. Deshalb arbeite ich parallel zu den Web-Projekten bewusst an den Grundlagen: Schleifen, Bedingungen, Datentypen, Funktionen, später Datenbanken und APIs.

Diese Übungsprojekte schreibe ich in Python, weil die Sprache wenig Ablenkung durch Syntax mitbringt und sich gut zum Nachdenken über Programmlogik eignet.

Mein Mentor-Setup

Ich habe mir einen GPT-Mentor konfiguriert, der die Rolle eines Senior Software Engineers übernimmt, ausgerichtet an der Schweizer Informatik-Ausbildung (Applikationsentwicklung EFZ, Wirtschaftsinformatik). Statt mir fertige Lösungen zu geben, stellt er mir Aufgaben, prüft meinen Code wie in einem Review und erklärt die Hintergründe jeder Entscheidung.

Der Schwerpunkt liegt bewusst nicht auf KI-Entwicklung, sondern auf klassischem Software Engineering: Clean Code, Testing, Git, Datenbanken, APIs und Architektur. KI ist dabei das Werkzeug und der Lehrer, nicht das Thema.

Zusätzlich nutze ich Codecademy, um mich laufend in der Programmierung weiterzubilden und über neue Konzepte auf dem aktuellen Stand zu bleiben.

Beispiel: CIS Ticket-System

Eine kleine Konsolen-Anwendung, die IT-Support-Tickets erfasst, inhaltlich angelehnt an meinen eigenen IT-Support. Sie fragt Daten ab, vergibt fortlaufende Ticketnummern und leitet aus der Priorität die passende Bearbeitungsfrist ab.

Welche Konzepte darin stecken

  • while-Schleife: mehrere Tickets nacheinander erfassen, bis die Nutzenden abbrechen
  • Benutzereingaben: einlesen mit input() und Umwandlung in Zahlen mit int()
  • Verzweigungen: if, elif, else für Volljährigkeit und Prioritätsstufen
  • f-Strings: lesbare Ausgabe mit eingebetteten Variablen
  • Zähler: automatisch fortlaufende Ticketnummern
  • Normalisierung: .lower(), damit «Hoch» und «hoch» gleich behandelt werden

Woran ich als Nächstes arbeite

  • Funktionen, um Wiederholungen im Code zu vermeiden
  • Fehlerbehandlung, damit ungültige Eingaben das Programm nicht abbrechen
  • Daten dauerhaft speichern (Datei, später Datenbank)
  • Erste automatisierte Tests
