C Visionary Studio

Mehrseitige Business-Website für ein Studio, das KI-generierte Videos, Bilder und Werbeinhalte für KMU erstellt, mein erstes grösseres Webprojekt.

Worum es geht

C Visionary Studio richtet sich an kleine und mittlere Unternehmen: Restaurants, Bars, Clubs, Fitnessstudios, lokale Marken, die professionelle Inhalte für Social Media brauchen, aber weder Zeit noch Budget für ein klassisches Filmteam haben.

Die Website muss deshalb zwei Aufgaben erfüllen: das Angebot verständlich erklären und Interessierte zu einer konkreten Anfrage führen. Sie ist bewusst als Verkaufsstrecke aufgebaut, nicht als reine Visitenkarte.

Screenshots

Was ich technisch umgesetzt habe

  • Mehrseitige Struktur: Startseite und eigene Preisseite mit gemeinsamer Navigation und einheitlichem Design, meine erste Website, die über eine einzelne Seite hinausgeht.
  • Animierter Hero-Bereich: Bewegter Sternenhimmel als Hintergrund, kombiniert mit gestaffelt einblendenden Textelementen.
  • Scroll-Animationen: Inhalte erscheinen beim Scrollen mit einer kurzen Verzögerung pro Element, gesteuert über data-Attribute im HTML.
  • Zielgruppen-Navigation: Auf der Preisseite können Besuchende ihre Branche wählen und sehen passende Beispiele.
  • Deployment über GitHub Pages: Der Weg vom lokalen Ordner über Git bis zur öffentlich erreichbaren Adresse: hier habe ich zum ersten Mal etwas wirklich veröffentlicht.

Was ich dabei gelernt habe

Dieses Projekt war mein Einstieg: erste eigene Website, erstes Repository, erstes Deployment. Hier habe ich gelernt, wie Git funktioniert, warum man Änderungen in Commits festhält und wie eine Seite überhaupt ins Internet kommt.

Rückblickend würde ich manches anders strukturieren, etwa das CSS stärker in wiederverwendbare Bausteine aufteilen. Genau dieser Vergleich zwischen damals und heute zeigt mir aber am deutlichsten, wie viel ich seither dazugelernt habe.
