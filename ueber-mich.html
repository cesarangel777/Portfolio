Über mich

Wie ich arbeite, wie ich lerne und was ich mitbringe.

Ich bin auf dem Weg in die Software-Entwicklung – und ich gehe ihn so, wie moderne Teams heute arbeiten: mit KI als Werkzeug, aber mit eigenem Verständnis für Struktur, Code und Prozess. Jedes Projekt in diesem Portfolio habe ich selbst konzipiert, umgesetzt und veröffentlicht.

Was mich antreibt: aus einer Idee etwas Echtes zu machen, das man anklicken, benutzen und zeigen kann. Dabei lerne ich mit jedem Projekt dazu – von sauberem HTML/CSS über JavaScript, Python und React bis zum Deployment und dem Arbeiten mit Git-Branches und Pull Requests.

Mein tägliches Werkzeug ist Visual Studio Code – hier schreibe, teste und versioniere ich meinen Code. Parallel dazu bilde ich mich strukturiert weiter: mit einem selbst konfigurierten GPT-Mentor, der mich wie ein Senior-Entwickler einen Junior ausbildet – mit Übungsaufgaben, Code-Reviews und Erklärungen zu den Hintergründen jeder Entscheidung.

Mit CIS – C IT Support betreibe ich ausserdem einen eigenen kleinen IT-Support-Service. Dort habe ich gelernt, technische Themen so zu erklären, dass sie auch ohne Vorwissen verständlich sind – eine Fähigkeit, die mir in jedem Entwicklerteam hilft.

Ich suche eine Junior-Stelle als Programmierer, bei der ich diese Arbeitsweise einbringen und unter erfahrenen Entwicklerinnen und Entwicklern weiter wachsen kann.

Meine Arbeitsweise mit KI

KI-Tools schreiben mit – aber ich entscheide. So sieht mein Workflow aus, mit dem jedes dieser Projekte entstanden ist:

1

Idee & Konzept

Ziel, Zielgruppe und Umfang definieren. Was soll das Projekt können, wie soll es sich anfühlen?

2

Struktur & Prompting

Seitenaufbau und Features klar beschreiben. Je präziser die Anforderung, desto besser das Ergebnis – das gilt für KI wie für Teams.

3

Umsetzung mit KI-Tools

Entwicklung im Dialog mit Claude Code & Co.: Code generieren, verstehen, hinterfragen und Schritt für Schritt verfeinern.

4

Testen & Review

Jede Änderung im Browser und auf dem Handy prüfen. Was ich nicht verstehe, lasse ich mir erklären – bis ich es erklären kann.

5

Git & Deployment

Versionierung mit Git, Zusammenarbeit über GitHub (Branches, Pull Requests), Veröffentlichung via GitHub Pages oder FTP.

Mein Lern-Setup: GPT als Mentor

Ich lerne nicht zufällig, sondern mit System: In VS Code arbeite ich an Übungsprojekten, während ein von mir konfigurierter GPT-Mentor die Rolle eines Senior Software Engineers übernimmt – ausgerichtet auf die Schweizer Informatik-Ausbildung (Applikationsentwicklung EFZ). Er stellt mir Aufgaben, macht Code-Reviews und erklärt die Hintergründe jeder Entscheidung. Der Fokus liegt auf Software-Engineering: Clean Code, Testing, Git, Datenbanken, APIs und Architektur – KI setze ich dabei bewusst als Werkzeug ein, nicht als Ersatz fürs eigene Verständnis.
